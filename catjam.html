Cat Jam - Rhythm Game

Built in Unity Engine, Cat Jam is a non-traditional rhythm game where notes gyrate and pulse to LoFi beats instead of scrolling linearly. Players control a dancing cat hitting notes to the beat in a vibrant, neon-drenched world.

As Design Lead, I reinvented standard rhythm game mechanics by implementing rotating note paths, dynamic hit windows, and a scoring system that rewards flow-state combos. The art style merges vaporwave aesthetics with playful feline animations.

Developed during a month-long passion project, with custom shaders for the note effects and hand-drawn cat sprites animated in Spine2D. The soundtrack features original LoFi tracks composed in FL Studio.
